# 码传 QRFloat

手机用**相机连续扫描二维码**，把内容**实时转发**给其他设备；接收端（手机或电脑）**实时显示**二维码和内容。适合"二维码每隔几秒就变（动态码）"的场景。

**无需自建服务器**：直接走公共 MQTT broker（`broker.emqx.io`），房间号就是 Topic 前缀。

## 功能

- **发送端**（手机）：选「发送二维码」→ 自动创建房间（随机 6 位号）→ 相机连续扫描 → 内容一变就实时发出
- **接收端**（手机 / 电脑）：输入房间号「加入」→ 实时接收并显示二维码 + 内容 + 房间人数
- **一对多**：一个房间只有一个发送端，可多个接收端
- **实时人数 / 发送端在线状态**
- **无需服务器**，装好即用
- 断线自动重连

## 房间机制（无服务器）

- 房间 = MQTT Topic 前缀 `qrfloat/<房间号>/`
- `members/<设备id>`：**保留消息**，每人每 10 秒心跳 `{ts, role}`，25 秒超时。用它来数人数、判断房主、判断房间是否存在
- `msg`：数据消息 `{type:"data", from, text}`
- **一源**：只有房主（`role=owner`）能发数据，接收端只接受房主的数据
- **创建房间**：自动挑随机空闲号（订阅检查，占用就换），永不失败
- **加入房间**：房主在线才成功，否则提示"房间不存在或已失效"

## 目录结构

```
app/                 Android 客户端（Kotlin + CameraX + ML Kit + Paho MQTT）
pc-receiver-src/     电脑接收端源码
  head.html mid.html tail.html app.js   单文件网页源码
  build.sh            组装单文件 HTML
  go-exe/             把网页封成单个可执行程序的 Go 源码（交叉编译 Windows exe）
```

## 构建

### Android

- 用 **Android Studio** 打开本目录，连手机 Run 即可（首次自动下载依赖）
- 或命令行：`./gradlew assembleDebug`，产物在 `app/build/outputs/apk/debug/`

### 电脑接收端

- 最简单：直接双击 `pc-receiver-src` 里生成的 `码传电脑接收端.html`，浏览器打开
- 或构建单文件可执行程序：见 `pc-receiver-src/go-exe/build.sh`（用 Go 交叉编译 Windows `.exe`）
- 需要先跑一次 `pc-receiver-src/build.sh` 生成 HTML（它会下载 mqtt.js / qrcode 并内联）

## 使用

1. 手机端选「发送二维码（创建房间）」→ 记下 6 位房间号
2. 接收端（另一台手机 / 电脑）输入房间号「加入」
3. 手机端「打开相机扫描发送」，对准二维码 —— 接收端会实时显示，随二维码变化更新

## 注意与限制

- **公共 broker 明文传输**：`broker.emqx.io` 是公共 MQTT，任何人订阅 `qrfloat/#` 都能看到所有 Topic 和明文内容。**请勿传输敏感信息**（付款码、密码等）。
- 房间号为 6 位随机数，创建时会自动避开已被占用的；但理论上仍可能被枚举或撞号。
- 房主崩溃后，房间最多约 25 秒自动释放（成员心跳超时）。
- 依赖免费公共 broker，稳定性/可用性不作保证。
- 如需私密/可靠：可自建 MQTT broker，把 App 里的「Broker 地址」改成你的即可。
